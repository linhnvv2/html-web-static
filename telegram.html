Telegram AI Bot

Bot AI trên Telegram

A local Retrieval-Augmented Generation (RAG) chatbot that answers questions from my personal PDF documents.

Chatbot RAG chạy trên máy chủ riêng, trả lời câu hỏi dựa trên tài liệu PDF cá nhân của tôi.

Chat with @VuLinhBotTrò chuyện với @VuLinhBot

How it works

Cách hoạt động

  • Chroma — vector database that stores and retrieves document embeddings.cơ sở dữ liệu vector lưu và truy xuất embedding của tài liệu.
  • LangChain — glue between the language model and the retrieval pipeline.kết nối mô hình ngôn ngữ với luồng truy xuất tài liệu.
  • Ollama — runs the language model locally to generate answers.chạy mô hình ngôn ngữ ngay trên máy chủ để sinh câu trả lời.
  • Flask — web layer and user interaction.lớp web và tương tác với người dùng.
